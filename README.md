# TV Navigator

TV Navigator is an AI-powered TV control system that lets users control their television using voice commands and hand gestures, removing the need for a traditional remote.

Built with Python, speech recognition, Google Speech-to-Text, and Google Media for gesture detection.

## 🧩 Features

Voice-based TV control

Hand gesture navigation

AI-driven command interpretation

## 🛠 Tech Stack

Python · Speech Recognition · Google SST · Google Media
